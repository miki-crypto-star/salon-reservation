# フルサービス美容室予約システム v2
1000円カット版ではありません。

## 主な機能
- カット・カラー・パーマ等、任意メニュー登録（料金登録なし）
- スタイリスト登録、対応メニュー、メニュー別施術時間
- 曜日別勤務時間、日別休み/勤務変更、休憩・予定ブロック
- 店舗定休日
- インターバル、退勤後延長許容
- 指名 / 誰でもOK
- 複数メニュー合計時間による空き枠計算
- 電話・LINE・店頭予約、予約変更、キャンセル
- ダブルブッキング防止
- お客様予約URL・QR表示
- 予約受付日数、当日予約、締切
- shopCodeによる店舗分離

## 公開
GitHubリポジトリの中身をこのZIPのファイルで完全に置き換えてください。
Firebase Authentication / Realtime Database は既存プロジェクトを使用します。
